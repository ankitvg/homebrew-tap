# ankitvg Homebrew Tap

Homebrew formulas for Ankit Gupta's CLI projects.

```sh
brew tap ankitvg/tap
```

## Projects

- `madari`: CLI tool to install, sync, and manage local MCP servers.
  Main repo: https://github.com/ankitvg/madari

  ```sh
  brew install madari
  ```

- `stew`: CLI for append-only markdown project memory ledgers.
  Main repo: https://github.com/ankitvg/stew

  ```sh
  brew install stew
  ```
